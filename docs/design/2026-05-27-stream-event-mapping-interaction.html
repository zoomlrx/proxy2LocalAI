响应映射工作台

配置目标页面期望收到的 SSE 结构。Proxy2LocalAI 会先把 Claude Code / Codex 的复杂流式事件转换成统一事件，再按这里的规则输出。

指引
普通用户只需要选模板、改 event 名和 data JSON。 标准事件、危险变量和 Provider 原始 JSONL 被放到说明、专家模式与安全策略里，避免基础配置被复杂字段淹没。

1. 选择内置模板

模板用于快速生成 streamMappings、doneEvent 和默认安全策略，可保存后继续细调。

当前：业务流式 SSE

2. 标准事件说明

把 Provider 原始输出翻译成用户可理解的通道，默认隐藏高风险字段。

标准通道 含义 默认是否返回 设计处理
messageAI 最终回答文本增量。是普通模式默认展示。
reasoning推理或思考文本增量。用户启用模板化开启，避免误传。
tool工具调用、审批、工具结果。用户启用进入安全策略隔离区。
statusProvider 生命周期状态。诊断显示默认不发给目标页面。
error错误事件。是需说明阶段与原因。
done流结束事件。是由 done policy 控制。

3. 映射规则编辑

普通模式只暴露最常用字段；专家 JSON 放在后置标签页中，并对危险变量即时提示。

启用 规则 标准事件 SSE event data JSON 模板 操作
风险
检测到危险变量。 `raw`、`data`、`tool.input`、`tool.output` 默认不会输出到目标页面，必须在安全策略中显式开启。

可用变量

{{content}} {{sequence}} {{eventId}} {{kind}} {{channel}} {{tool.name}} {{tool.status}} {{meta.model}} {{raw}} {{data}} 
事件名校验：^[A-Za-z0-9_.:-]{1,80}$
缺失变量：默认 empty_string
渲染失败：默认 skip_frame
data 编码：第一阶段固定 JSON.stringify()
